# Catálogo Interativo de Produtos

Trabalho 1 - Programação para Web

## Integrante

- Fernando Otávio de Sousa cunha Lima

## Funcionalidades

- Listagem de produtos com nome, imagem e preço
- Pesquisa de produtos por nome
- Detalhes do produto
- Favoritos (adicionar e remover)
- Mensagem de carregamento
- Aviso de erro quando a API falha

## Como executar

Abra o arquivo index.html no navegador. É necessário estar conectado a internet.
